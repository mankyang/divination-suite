这是什么

本包将 skill-bazi（八字）、skill-ziwei-doushu（紫微斗数）、skill-qimen-dunjia（奇门遁甲）、taibu-divination（通用排盘引擎） 四个独立 Skill 整合为单一可发布应用：taibu 引擎作为唯一计算层，三个体系的深度解读资料归档为分层解读库，由统一入口 SKILL.md 路由。原 Python 排盘脚本未纳入（功能已被引擎覆盖），避免双引擎口径分裂。

快速验证

unzip divination-suite.zip && cd divination-suite
node scripts/taibu.mjs list
echo '{"gender":"male","birthYear":1990,"birthMonth":5,"birthDay":20,"birthHour":8}' \
  | node scripts/taibu.mjs call bazi -

唯一要求：Node.js 18+。无网络、无 pip、无数据库依赖。
